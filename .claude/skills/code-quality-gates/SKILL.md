# 코드 품질 게이트

CLAUDE.md의 구현 지침에 명시된 품질 기준을 "눈대중"이 아니라 실제 도구 실행 결과로 판정합니다. 도구를 안 돌리고 "괜찮아 보인다"고 판단하는 것은 이 스킬을 따른 것이 아닙니다.

## 참조 파일

| 파일 | 언제 읽는가 |
|---|---|
| `references/tools-and-thresholds.md` | 각 게이트를 실행할 정확한 명령어와 임계값을 확인할 때 (항상 먼저) |
| `references/doxygen-comment-format.md` | 주석 게이트 위반을 고치거나 새 코드에 주석을 쓸 때 |
| `references/naming-convention.md` | 네이밍 게이트 위반을 고치거나 새 식별자 이름을 지을 때 |

## 5가지 게이트

| # | 게이트 | 기준 | 도구 |
|---|---|---|---|
| 1 | 함수 라인수 | 순수 코드 라인(NLOC, 주석/공백 제외) 50줄 이하 | `lizard` |
| 2 | 순환복잡도 | 함수당 CCN — 프로젝트 합의 기본 임계값 10 (CLAUDE.md에 구체적 수치가 없어 채택한 관례값, 다르게 정하고 싶으면 사용자에게 확인) | `lizard` |
| 3 | 중복코드 | 8줄 이상 중복은 위반 (7줄까지는 허용) | `pylint` (`duplicate-code`, `min-similarity-lines=8`) |
| 4 | 주석 비율 | 파일 기준 (comments + multi) / loc ≥ 0.20, Doxygen 형식(`@brief`/`@param`/`@return`) | `radon raw` (비율 계산) + `doxygen` (형식·누락 검증) |
| 5 | 네이밍 | 함수명/변수명 3글자 이상, camelCase (클래스명 제외) | `pylint` (`.pylintrc` 네이밍 규칙) |

## 작업 절차

1. **대상 확인.** 이번에 검사할 파일/모듈을 확인합니다(보통 `tdd` 스킬의 Refactor 단계에서 방금 작성/수정한 파일).
2. **도구 실행.** `references/tools-and-thresholds.md`의 정확한 명령어로 5가지 게이트를 모두 실행합니다. 도구가 설치되어 있지 않으면 설치 명령을 안내하고 실행하세요(임의로 게이트를 생략하지 마세요).
3. **결과 판정.** 각 게이트를 통과/위반으로 판정하고, 위반이 있으면 도구 출력에서 파일명·줄 번호·함수명을 그대로 인용합니다. "대체로 괜찮다"처럼 뭉뚱그리지 마세요.
4. **수정 제안.** 위반마다 구체적인 수정 방향을 제시합니다:
   - 함수 라인수 초과 → 어느 부분을 별도 함수로 뽑아낼 수 있는지 지목
   - 순환복잡도 초과 → 어느 분기/조건을 정책 의사결정표나 조회 테이블로 바꿀 수 있는지 지목
   - 중복코드 → 공통 부분을 뽑아낼 함수/모듈 이름을 제안
   - 주석 비율/형식 미달 → 어느 함수에 Doxygen 주석이 없는지 지목 (`references/doxygen-comment-format.md` 형식으로)
   - 네이밍 위반 → 구체적인 대체 이름 제안 (`references/naming-convention.md` 규칙으로)
5. **재검증.** 수정 후 5가지 게이트를 다시 실행해 전부 통과하는지 확인합니다. 하나라도 실패하면 "다음에 고치겠다"고 미루지 말고 이 자리에서 반복하세요.

```markdown
|---|---|---|
| 함수 라인수(≤50) | 통과/위반 | lizard 출력 인용 |
| 순환복잡도(≤10) | 통과/위반 | lizard 출력 인용 |
| 중복코드(≤7줄) | 통과/위반 | pylint 출력 인용 |
| 주석비율(≥20%, Doxygen) | 통과/위반 | radon raw 계산값 + doxygen 경고 |
| 네이밍(3자+ camelCase) | 통과/위반 | pylint 출력 인용 |

### 위반 수정 제안
1. ...
```

## 하지 말아야 할 것

- 도구를 실행하지 않고 코드를 눈으로만 보고 통과 판정을 내리지 마세요.
- 순환복잡도 임계값(10)처럼 CLAUDE.md에 명시되지 않은 값을 근거 없이 확정값처럼 말하지 마세요 — "이 스킬이 채택한 기본값"이라고 밝히세요.
- 위반을 발견하고도 "사소하니 넘어간다"고 스스로 판단하지 마세요 — CLAUDE.md는 이 지표들을 **반드시** 준수하라고 명시했습니다.
