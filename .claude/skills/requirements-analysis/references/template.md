## 추적 매트릭스와의 관계

`ENG-TRC-001`(`TPL-TRC-001_양방향 요구사항 추적 매트릭스`)의 열 구성은 **Upper Req | SW Req | Architecture | Detailed Design | Code | SWE.4 | SWE.5 | SWE.6 | Coverage**이며, 이 스킬은 **Upper Req → SW Req** 구간을 채우는 책임을 집니다. "Upper Req"에는 상위 입력 문서(고객 요구사양서 등)의 요구사항 ID를 그대로 쓰고, "SW Req"에는 이 스킬이 부여한 ID를 씁니다 — 상위 입력이 이미 SW 요구사항 ID 체계(예: `SWR-###`)를 지정했다면 `references/traceability.md`의 기본 접두사(`SWE-REQ-####`)보다 그 지정된 체계를 우선합니다.
